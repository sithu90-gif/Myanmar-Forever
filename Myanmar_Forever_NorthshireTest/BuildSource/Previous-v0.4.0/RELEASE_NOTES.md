# MyanmarForever v0.4.0-beta

Night Elf အစပိုင်း Quest 121 ခု ထပ်ထည့်ထားပါတယ်။ စုစုပေါင်း Quest ID 474 ခုနဲ့
လက်ခံချိန်၊ လုပ်ဆောင်ဆဲအချိန်၊ ပြီးဆုံးချိန်အတွက် စာသားအခြေအနေ 1,312 ခု ပါဝင်ပါတယ်။
ဘာသာပြန်အသစ်တွေကို မြန်မာစာ ပြန်လည်စစ်ဆေးမှုနဲ့ ဂိမ်းထဲ စမ်းသပ်မှု လိုအပ်ပါသေးတယ်။

Myanmar Forever အတွက် Key Bindings 6 ခု ထည့်ထားပါတယ်။ Scroll၊ ပိတ်ဖွင့်နဲ့
စာလုံးအရွယ်အစားကို ကိုယ်ပိုင်ခလုတ် သတ်မှတ်ပြီး သုံးနိုင်ပါတယ်။ `/mmforever` ကိုလည်း
သုံးနိုင်ပြီး `/mmnorth` အဟောင်း ဆက်အလုပ်လုပ်ပါတယ်။ Font ပြောင်းထားလို့
တင်ပြီးရင် ဂိမ်းကို လုံးဝပိတ်ပြီး ပြန်ဖွင့်ပါ။

## Added

- 121 Night Elf quest drafts: Shadowglen 14; Teldrassil 33; Darkshore 69;
  Warrior, Hunter, Rogue, Priest and Druid introductions 5.
- 572 translated fields, including 331 additional dialogue states.
- Optional bindings for toggle, scroll up/down, close, and font size up/down.
- `/mmforever` alias and matching macro commands.
- A portable font/catalog build with bundled font inputs and reviewable sources.

## Preserved

All 353 prior quest records are unchanged. The draggable/resizable reader,
first-open reflow, identity expansion, debug controls, automatic local captures,
saved settings, and original installation folder remain compatible.

## Source and review status

The Night Elf set covers the selected regional quests through reference level 20;
it is not a claim to include every profession, class or higher-level chain.
English references are linked per quest in `Night-Elf-Review.html`. Some are
Classic Era records linked from the Forever listing and may differ in game.
New quests have not been captured or verified in the live Forever client.

Quest 3118 progress is held because the source contains a fixed player name.
Quest 4723 has conflicting creature descriptions in its reference; confirm in game.
Quest 1003 progress summarizes the sung passage as a stage direction.
The prior hold on quest 95213 completion remains. Absent and held fields use the
native quest window as the fallback; missing text is not invented.

Automated checks passed for all 474 quests across three dialogue states,
all 2,255 runtime fields, Myanmar shaping boundaries, font coverage, numeric
digits, identity markers, previous records, binding actions and delayed close.
These are offline checks; native-language review and live-client/controller
validation remain pending. This beta is ready for that testing, not a verified
production release. See `TESTING.txt` for the short test route.
