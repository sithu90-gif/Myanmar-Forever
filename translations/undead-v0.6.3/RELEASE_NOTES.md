# MyanmarForever v0.6.3-beta-candidate

Prepared November 5, 2026. This is a testing candidate.

- Adds 24 Undead starter quest records covering Deathknell, the Brill handoff and supported early class introductions.
- Adds 106 translated fields using the conversational style approved in the first two samples. English names retain Myanmar pronunciation; the existing first-introduction meanings remain available.
- Total coverage: 688 quest IDs, 3,240 translated fields and 1,879 available dialogue states.
- Preserves all 664 earlier quest translations and existing controls, layout and runtime code.
- Leaves 13 unavailable source states absent and one additional gender-dependent reply held for live confirmation.
- Regenerates the bundled font and quest catalog together. Source-integrity, glyph, Unicode round-trip and Lua regression checks pass.

Fully exit WoW before replacing the complete `Myanmar_Forever_NorthshireTest` addon folder. Keep its folder name. Commands: `/mmforever` and `/mmnorth`.

Full native Myanmar proofreading, current live Forever testing and controller checks remain pending. This update covers the starter area and handoff; later Tirisfal and Silverpine quests remain future work.

The first two review samples were approved by the project owner, who authorized continuation in that style. Remaining wording and new pronunciations are assisted editorial drafts. English source records were read from 60.tools Forever; UA_Forever 0.23.0 was used as secondary identity/state evidence. DeepL MY supplied comparison drafts that were edited for meaning, names and voice.
